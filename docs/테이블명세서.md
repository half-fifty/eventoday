# 테이블 명세서

## 박람회·행사 예약 및 부스 운영 플랫폼 테이블 명세서

> PostgreSQL 기준 권장 설계안. 확정된 요구사항을 기준으로 중복 테이블과 불필요한 컬럼을 제거하고, 행사당 단일 티켓 구조를 반영하였다.

이 명세는 [V1__init_schema.sql](../BE/src/main/resources/db/migration/V1__init_schema.sql) 마이그레이션의 기준 문서입니다. 실제 컬럼/제약조건은 마이그레이션 파일이 최종 소스이며, 이 문서는 설계 의도를 설명하는 용도입니다.

## 공통 규칙

- PK는 `BIGINT` Identity를 사용한다.
- 날짜·시간은 `TIMESTAMPTZ`로 저장한다.
- 금액은 소수점 단위 `NUMERIC(12, 0)`을 사용한다.
- 상태값은 `VARCHAR(30)`과 Java Enum으로 관리한다.
- 일반 업무 테이블에는 `created_at`, `updated_at`을 공통 적용한다.
- `PK`: 기본키, `FK`: 외래키, `UK`: 고유키, `CK`: 체크 제약조건

# 14. 핵심 관계 요약

```
members
 ├─ organization_members → organizations
 ├─ admission_tickets
 ├─ booth_interests
 ├─ booth_reservations
 └─ booth_reviews

organizations
 ├─ events
 ├─ booth_applications
 └─ advertisements

events
 ├─ booth_recruitments
 ├─ booths
 ├─ venue_maps
 ├─ ticket_orders
 └─ advertisements

booth_recruitments
 └─ booth_applications → booths

venue_maps
 └─ booth_map_positions → booths

ticket_orders
 └─ exchange_codes
     └─ admission_tickets

booths
 ├─ booth_interests
 ├─ booth_reservation_slots
 │   └─ booth_reservations
 ├─ booth_qr_scans → exchange_codes
 ├─ booth_reviews
 └─ booth_hourly_statistics
```

이 명세는 **총 29개 테이블**로 구성된 행사당 단일 티켓 구조의 최종안이다.
